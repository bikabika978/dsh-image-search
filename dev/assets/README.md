# 测试素材（CC0）

这里的两张图由本项目用 `sharp` 从内联 SVG 生成，**不包含任何第三方素材**，随仓库以 **CC0 1.0（公有领域贡献）** 释出：可以自由复制、修改、商用、再分发，无需署名。

| 文件 | 尺寸 | 用途 |
|---|---|---|
| `cc0-shapes-640x480.png` | 640×480 | 冒烟测试默认图，验证链路是否跑通 |
| `cc0-gradient-480x360.jpg` | 480×360 | 备用的 JPEG 路径测试图 |

## 注意

这两张是**抽象几何图**，任何引擎都认不出具体内容——冒烟测试要验证的是"链路能通、返回结构正确"，不是"识别准确"。

想验证识别效果，请自己传一张真实图片：

```bash
node dev/smoke-test.mjs "D:/素材/某张动漫角色图.jpg"
```
